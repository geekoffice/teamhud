# Contributing

Thanks for helping. The most useful things right now:

- **Good bug reports.** Use the [bug form](../../issues/new/choose): computer, TeamHUD version, steps, expected, actual. One problem per issue.
- **Examples.** A small, working widget or wallpaper with a README. Open a pull request under `examples/<name>/`.
  - Use the `th-*` elements and `--th-*` tokens, no hard-coded colours or pixel sizes.
  - A widget declares only the permissions it needs; a new example should ask for none unless it truly needs one.
  - No secrets, personal data or private URLs.
  - Say in the README which TeamHUD version you tried it on.
- **Ideas.** Use the [feature form](../../issues/new/choose), or talk it over in Discord first.

By contributing you agree your contribution can be shared under this repository's licence.
