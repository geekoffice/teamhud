# Pebble: a sound pack

A **sound pack** is a folder with a `pack.json` and, if you like, some short audio files. It sets
what TeamHUD sounds like when you join or leave a call, when a teammate does, when someone rings
you, and when a message arrives. Pebble is soft, woody two-note cues: rising means someone
arrived, falling means someone left.

```
sound-pack-pebble/
  pebble/            the pack itself: this is the folder you install
    pack.json        names the pack and says which sound plays for which event
    join.wav  leave.wav  peer-join.wav  peer-leave.wav  ring.wav  message.wav
  make-sounds.mjs    the script that generated the .wav files
  README.md          this file
```

Written against TeamHUD **1.0.0-alpha.1**.

## Install

1. Copy the **`pebble`** folder (not this whole example) into `.teamhud/soundpacks` in your home
   folder: `~/.teamhud/soundpacks/pebble/` on macOS and Linux,
   `%USERPROFILE%\.teamhud\soundpacks\pebble\` on Windows.
2. TeamHUD watches that folder; the pack appears after a second or two, no restart.
3. Open Preferences → **Sounds** and click the **Pebble** card. If you've tuned volumes before,
   you'll be asked whether to **Keep my volumes** or **Use pack volumes**.

The **folder name is the pack's id**, and becomes part of the URL TeamHUD plays the files from, so
keep it to lowercase letters, numbers and dashes. To remove the pack, use the trash icon on its
card or delete the folder.

## Change it

`pack.json` lists events under `pack.events`. Each event has `enabled`, a `volume` from 0 to 1,
and a `source`:

| Source | Example | Use it for |
|---|---|---|
| A file in the pack folder | `{ "kind": "file", "src": "join.wav" }` | Your own recordings. `src` is a bare file name: no folders, no leading dot. |
| A synthesised tone | `{ "kind": "tone", "tone": { "kind": "blip", "freq": 392, "durationMs": 90, "wave": "triangle" } }` | Zero-byte sounds. Pebble uses these for mute and unmute. Tone kinds: `blip`, `slide` (`from`, `to`), `chord` (`freqs`), `sequence` (`steps` of `freq`/`durationMs`/`gapMs`), `noise`, `layers`. `wave` is `sine`, `triangle`, `square` or `sawtooth`. |
| A built-in preset | `{ "kind": "preset", "id": "ascend" }` | TeamHUD's own sounds by name. |

Event names: `localJoin`, `localLeave`, `peerJoin`, `peerLeave`, `callInvite`, `selfMute`,
`serverMute` (a moderator muted you), `selfUnmute`, `selfDeafen`, `selfUndeafen`,
`messageReceived`, `messageSent`. **Leave an event out and it keeps TeamHUD's default sound**;
Pebble leaves out deafen, moderator-mute and message-sent on purpose. An event name TeamHUD
doesn't know is ignored, and a source it can't use falls back to the default for that one event,
so one mistake never costs you the whole pack.

**Audio files:** WAV, Ogg, MP3 or M4A (TeamHUD checks the file's first bytes, not its
extension), at most 512 KB each. Keep cues short; under a second is plenty. Your master volume
and output device are never set by a pack: they belong to whoever is listening.

To make your own sounds the way Pebble's were made, edit the notes at the bottom of
`make-sounds.mjs` and run `node make-sounds.mjs` in this folder (Node 18 or newer, no
packages). It rewrites the files in `pebble/`.

You can also start in the app: pick sounds in Preferences → Sounds and press **Save as pack…**.
TeamHUD writes a new folder in `~/.teamhud/soundpacks/` you can open and edit.

## Where the sounds came from

Every sound in this pack was generated by `make-sounds.mjs` from sine waves, written for this
example: no recordings, samples or third-party audio. Like everything else in this repository
they're under the [MIT licence](../../LICENSE).

## Safety

A pack is data: names, numbers and audio. TeamHUD only plays files from inside the pack's own
folder, refuses anything that isn't audio, and caps file sizes. Packs are shared between people,
so every pack is checked the same way whether you dropped it in or it came with a theme.
